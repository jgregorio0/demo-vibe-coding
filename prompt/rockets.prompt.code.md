# Spec
## Role
Act as a software developer.

## Task
Implement the functionality described in the specification provided.
Do not write tests or documentation, just the production code.

## Context

A file `specs/rockets.spec.md` is provided with the specification.
Ask for the specification if not provided.
A file AGENTS.md is provided with common coding rules. Follow them carefully.

## Code guidelines
- Follow AGENTS.md file.

## Steps to follow
1. Ensure clean GIT: stop process if any changes are not commited before starting.
2. Understand the specification: read the context to grasp the requirements and the business problem.
3. Break it down: divide the functionality into smaller, components.
4. Have a plan: generate the steps to implement the functionality.
5. Prepare GIT: Create a branch 'feat/rockets'
6. Implement the functionality: write the code following the plan. Do not write tests or documentation, just the production code.

## Output checklist
- [ ] A new branch 'feat/rockets' with the implementation of the functionality.
- [ ] Production code ready to be committed.
